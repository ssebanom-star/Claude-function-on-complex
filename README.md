# 복소평면 위 n차 다항식 해 시각화

n차 함수 `f(x)` 를 입력하면, **복소수 x 평면**(가로: 실수부, 세로: 허수부)과
**함숫값의 절댓값 `|f(x)|`** 를 높이축으로 삼아 3차원 곡면을 그립니다.

### 📐 3D / 4D 표시 방식

복소함수 `f(x)`의 그래프는 입력 2차원(실수부·허수부)과 출력 2차원(실수부·허수부)을 합쳐
**ℝ⁴ 공간 안에 놓인 2차원 곡면**입니다. 두 가지 방식으로 볼 수 있습니다.

- **3D (높이 = |f|)**: x평면 위에 `|f(x)|`를 높이로 올린 곡면. 바닥에 닿는 골짜기가 해입니다.
- **4D 투영 (ℝ⁴ → ℝ³)**: `(Re x, Im x, Re f, Im f)` 4차원 좌표를 그대로 사용합니다.
  출력 크기는 `log(1+|f|)`로 압축하고 위상은 보존해, 해는 정확히 `(a, b, 0, 0)`에 위치합니다.
  - **XW / YW / ZW 회전 슬라이더**: 4번째 축(w)을 3차원 공간 안으로 회전 (4D 평면 회전)
  - **원근투영**: 테서랙트(4차원 정육면체)를 그릴 때와 같은 표준 원근투영으로 ℝ⁴ → ℝ³
  - **색상**: 위상 `arg(f)`(순환 색상) 또는 크기 `|f|`로 표면을 칠해, 잃어버린 차원의 정보를 색으로 표현
  - 투영된 결과는 다시 마우스/터치로 3D 회전할 수 있습니다.

## 파이썬(데스크톱) 버전

방정식 `f(x) = 0` 의 해에서는 `|f(x)| = 0` 이므로,
곡면이 바닥에 닿는 **골짜기(구멍)** 가 바로 그 해입니다.
n차 방정식이 가지는 n개의 복소근(중근 포함)을 한눈에 볼 수 있습니다.

## 핵심 아이디어

| 축 | 의미 |
|----|------|
| x축 | 복소수 `x = a + bi` 의 실수부 `a` |
| y축 | 복소수 `x = a + bi` 의 허수부 `b` |
| z축 (높이) | 함숫값의 절댓값 `|f(x)|` |

- 실수근: 허수부 = 0 (가운데 줄) 위의 골짜기
- 복소근: 평면 위 어디든 나타나는 골짜기
- 빨간 점: `numpy.roots` 로 계산한 정확한 근의 위치

## 사용법

계수는 **최고차항부터 상수항 순서**로 입력합니다.

```bash
# x^2 + 1  (근: ±i)
python polynomial_root_viz.py --coeffs 1 0 1

# x^3 - 1  (근: 1, 그리고 켤레 복소근 2개)
python polynomial_root_viz.py --coeffs 1 0 0 -1

# x^3 - 6x^2 + 11x - 6  (근: 1, 2, 3)
python polynomial_root_viz.py --coeffs 1 -6 11 -6

# 대화형 입력
python polynomial_root_viz.py

# 화면이 없는 환경에서 그림 파일로 저장
python polynomial_root_viz.py --coeffs 1 0 1 --save out.png
```

### 옵션

| 옵션 | 설명 |
|------|------|
| `--coeffs`, `-c` | 계수 (최고차항부터). 복소 계수는 `1+2j` 형태 |
| `--span`, `-s` | 보기 범위 `±span` (미지정 시 근 위치 기준 자동) |
| `--resolution`, `-r` | 격자 해상도 (기본 300) |
| `--log` | 높이축을 `log(1+|f|)` 로 (작은 골짜기를 강조) |
| `--save` | 화면 대신 PNG 파일로 저장 |

> 한글 폰트가 없는 환경에서는 그래프 라벨이 자동으로 영어로 표시됩니다.
